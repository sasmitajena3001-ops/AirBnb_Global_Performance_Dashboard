# AirBnb_Global_Performance_Dashboard

An end-to-end Power BI dashboard project, explained step by step on my YouTube channel (Mansi G.). It covers data modeling, DAX, Pareto analysis, seasonality, pricing and trust insights, and focuses on why each design decision matters as well as how to build it.

Download the dataset here: https://mavenanalytics.io/data-playground/airbnb-listings-reviews
